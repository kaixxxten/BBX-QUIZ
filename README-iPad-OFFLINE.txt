BEYBLADE X QUIZ — 正式版（1017＋PWA）
=======================================

本資料夾是唯一正式維護版本
--------------------------
- 線上網頁、電腦瀏覽器與 iPad PWA 共用同一份 index.html。
- 介面、題庫與遊戲邏輯不分成兩套。
- PWA 只增加離線資料、快取、圖示與主畫面啟動功能。

重要
----
本版本不要從 iPad「檔案」App 直接點 index.html。
那會進入 Quick Look，可能只顯示畫面而不執行 JavaScript，造成按鈕無反應。

正確安裝方式
------------
1. 將整個資料夾上傳至支援 HTTPS 的網站空間（例如 GitHub Pages）。
2. iPad 連網後，用 Safari 開啟 index.html 網址。
3. 等待首頁顯示後至少 10 秒，讓題庫與圖片完成離線快取。
4. 點 Safari 的「分享」。
5. 選擇「加入主畫面」，並開啟「作為 Web App 打開」。
6. 回到 iPad 主畫面，點 BBX QUIZ 圖示啟動一次。
7. 開啟飛航模式，再次關閉並重開 BBX QUIZ，完成活動前驗收。

活動前必測
----------
- 動畫題按鈕可進入難度頁
- 陀螺題按鈕可進入難度頁
- 一般模式顯示 1 / 10，作答後能進下一題
- 60 秒極限挑戰倒數正常
- TOP 可返回首頁
- 圖片題可以顯示及點選
- 關閉 App 後，在飛航模式重新開啟仍可使用

離線內容
--------
- 4 個 TXT 題庫
- settings/page_text.txt
- settings/staff.txt
- 所有題目圖片
- HTML、CSS、JavaScript
- PWA 圖示與 manifest

本專案沒有外部 CDN、外部 API 或線上字型依賴。

更新題庫或圖片
--------------
最簡單的正常更新流程：

1. 修改 questions、settings、images 或 index.html。
2. 在 Windows 雙擊：

  更新iPad離線版.cmd

3. 確認畫面顯示「更新完成」。
4. 將整個資料夾一起發布到原本網站位置。
5. 若使用 GitHub Pages，請一次提交所有變更。
6. iPad 保持連網，完全關閉 BBX QUIZ 後重新開啟。
7. 首頁會主動檢查新版；新版快取完成後會自動重新載入一次。
8. 再開啟飛航模式，確認新版題目與圖片可以離線使用。

不要只上傳單一 TXT
-------------------
更新程式會同步產生 offline-data.js 與新的 sw.js 快取版號。
因此發布時至少要一起上傳：

- 修改過的 questions、settings、images 或 index.html
- offline-data.js
- sw.js

最安全的方式仍是每次發布整個資料夾。

快取更新機制
------------
- 更新程式會計算 HTML、題庫、設定、圖片、圖示的 SHA-256 內容雜湊。
- 只要任一執行檔內容有變，sw.js 的 cache name 就會自動改變。
- iPad 每次開啟時都會直接檢查 sw.js，不使用舊的 HTTP 快取版本。
- 新 Service Worker 會先完整快取新版，再接管頁面。
- 若接管時仍停在首頁，頁面會自動重新載入一次，統一切換成新版。
- 舊 cache 會在新版啟用後自動刪除。
- 若當下完全離線，更新檢查失敗不會影響既有離線版遊玩。
